清池 0.1.0 Windows x64 便携测试版

重要边界：这是独立窗口原型，不是已挂载到桌面的动态壁纸。
打包时已校验官方 Electron 运行时校验和、x64 PE 结构、ZIP 完整性及应用文件一致性。
当前构建环境为 Mac；Windows 启动、输入、多屏、休眠恢复尚未实测。
没有配置开机自启、注册系统服务、修改桌面壁纸或发布安装器。

使用：完整解压 ZIP 到你有写权限的文件夹；不要只取走 EXE。双击 Qingchi.exe。
依赖文件均在解压目录中，无需另装 Node.js。未经清池发行签名，Windows 可能提示未知发布者；若系统拦截，先核对来源与校验和，不要关闭系统安全保护。
数据：原型存档在 resources/app/runtime-profile 内。移动时保留整目录；删除目录前先在设置中导出备份。
便携测试版不适合放在只读目录或 Program Files。将来正式安装版会采用独立用户数据目录及升级迁移。

最低验收项（均待 Windows 实测，不预填通过）：
[ ] 启动成功，18 条鱼持续游动，页面无脚本错误。
[ ] 记手笺、添加完成待办，退出重开后保持。
[ ] 点击组件不投喂，点击空白水面投喂，安静模式不投喂。
[ ] 专注启动、暂停、重载继续；设置中三秒测试提醒正常。
[ ] 导出/导入往返，无效备份不覆盖旧数据。
[ ] 缩放 100%/150%/200% 时可用，拖到另一屏显示正常。
[ ] 系统休眠唤醒后计时、渲染正常，关闭应用不留后台窗口。
