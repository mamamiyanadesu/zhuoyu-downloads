      城市天气

      城市级位置，非 GPS 定位。启用后向 Open-Meteo 请求天气，数据为模型估算。手动改天气将停止自动联动。

      画面天气

      手动调整只改变画面，不代表实况。

      春秋独立复刻对照；原版代码与美术未直接打包。切换期间保持上一幅完整画面。

      开始钓鱼

      抛竿 → 等待咬钩 → 提竿 → 按住/松开控制力度。让指针留在绿色区，进度满格即可钓获。

      竹影竿
      准备好，就抛一竿。
      松 ← 力度 → 紧0%

      这是离线轻玩法；鱼币不是现金，也没有购买入口。

      最多 12 尾。可锁定、出售或放流；“放入鱼池”会转入我的鱼，之后不再作为鱼篓商品。
