清池 · 0.1.0 组件原型（2026-11-06）

本轮目标：按“碧潭的组”理解为“碧潭的组件”，借鉴功能，独立实现。
已完成：MIT 鱼池 + 手笺 + 按本地日期的待办 + 25 分钟专注/5 分钟休息 + 页面内到时提醒 + 本地保存 + JSON 备份恢复 + 暂停/沉浸/鱼数量/帧率上限设置。
没有实现：钓鱼、商店、天气服务、每日文案、自绘鱼、快捷启动、远程激活、桌面挂载、开机自启、多屏挂载与原生置顶提醒。
外观为独立的简约池塘原型，不宣称复刻碧潭的画质或超过商业程序。

打开方式：
1. Mac：双击本目录“打开清池.command”。官方 Electron 已装在本项目 node_modules 中。首次可能需按系统正常权限流程允许打开。
2. 网页：双击 app/index.html 可尝试离线打开；推荐运行 python3 scripts/preview_server.py，再访问 http://127.0.0.1:8786 。不同打开来源的存档独立，可通过备份迁移。
3. Windows：使用 releases 中的便携 ZIP，完整解压后打开 Qingchi.exe。请先阅读 WINDOWS验收.txt；仅打包，尚未 Windows 实机验收。
4. 从源码重装桌面依赖：Node.js >=22.12，执行 npm ci，再执行 npm run setup-runtime，再执行 npm start。Electron 45 不会只靠 npm install 自动下载运行时。

操作：
- 点击水面投喂；右侧切换手笺、待办、专注。
- H 收起/恢复组件，输入框中按 H 不触发快捷键。
- 手笺即时自动保存；保存失败会明确提示“未保存”。
- 待办默认显示今天，可查看历史日期；删除操作立即保存。
- 计时使用截止时间，刷新可继续；页面关闭时没有后台通知，重开后补记到时状态。
- 备份导入会询问是否替换；无效备份不会覆盖原数据。不同宿主的 localStorage 不自动互通。
- 暂停是停止鱼池模拟/绘制，不停止专注时钟。帧率显示为设置上限，不是测得帧率。

数据边界：
开发版桌面数据位于本目录 runtime-profile；网页数据在该浏览器相应来源的 localStorage。
没有上传接口。异常存档会暂停自动覆盖；可以导出当前内容或导入有效备份。
不适合多个窗口同时编辑同一份手笺：遇到同步冲突会提示先备份再刷新。

验收：
Node 核心测试在 tests/core.test.cjs；浏览器交互证据、截图及 Mac 原生窗口记录在 evidence。
原始鱼池与修改版、回滚版的相同输入测试在 transaction/VERIFICATION.txt。
四角色固定为 app/vendor/pond.js、transaction/DIFF.patch、transaction/VERIFICATION.txt、transaction/ROLLBACK.sh。
ROLLBACK.sh 只将传入的鱼池引擎副本恢复为原始 MIT 引擎，不是卸载整个清池工程。建议传入独立测试副本，不覆盖当前成品。
